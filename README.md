# Pokémon Pack Card Simulator — คู่มือผู้เล่น

เว็บไซต์คู่มือแบบ static แยกจากตัวเกม ไม่มีการเชื่อมต่อฐานข้อมูลหรือแก้การทำงานของเกม

## เปิดใช้งาน

- เปิด `index.html` ในเบราว์เซอร์เพื่ออ่านในเครื่อง
- หากต้องการให้ผู้เล่นเข้าผ่านอินเทอร์เน็ต ให้อัปโหลดโฟลเดอร์ `game-guide` ทั้งโฟลเดอร์ไปยัง static hosting เช่น GitHub Pages, Netlify หรือ Cloudflare Pages
- ตั้ง `index.html` เป็นหน้าแรก และแชร์ URL ของเว็บคู่มือให้ผู้เล่น

ข้อมูลที่เปลี่ยนได้ง่าย เช่น มูลค่าการ์ดและค่าธรรมเนียมอัปเกรดอยู่ใน `assets/guide-data.js` ส่วนกติกาและคำอธิบายอยู่ในไฟล์ HTML ของแต่ละหน้า

ข้อมูลภารกิจ แพ็ค และกติกาอ้างอิงจากเกม ณ วันที่จัดทำ อาจเปลี่ยนได้หากมีการแก้ไขระบบเกม
